# Job Tracker

A free desktop app for Windows and Linux that finds LinkedIn job listings for
your saved search terms and tracks every application from **Applied** to **Offer**.

Website: https://job-tracker-gilt-phi.vercel.app

## Download

Get the latest version from the [Releases page](https://github.com/kiokoDS/job_tracker/releases/latest):

| Platform | File |
|---|---|
| Windows 10 / 11 (64-bit) | [`JobTracker.exe`](https://github.com/kiokoDS/job_tracker/releases/latest/download/JobTracker.exe) |
| Linux (64-bit) | [`JobTracker-linux`](https://github.com/kiokoDS/job_tracker/releases/latest/download/JobTracker-linux) |

**Windows:** double-click `JobTracker.exe`. If Windows shows *"Windows protected
your PC"*, click **More info → Run anyway** (the app isn't code-signed yet).

**Linux:** make it executable, then run it:

```sh
chmod +x JobTracker-linux
./JobTracker-linux
```

Your job list is saved in `jobs.db`, in the same folder as the app.
